# Student Spending Analysis

## Project Overview
This beginner-friendly data analysis project explores monthly spending patterns among six fictional students using Python.

The goal is to practice data manipulation, basic statistical analysis, and data visualization.

## Technologies Used
- Python
- pandas
- Matplotlib
- Google Colab

## Project Features
- Calculate total monthly expenses for each student
- Identify the highest and lowest spenders
- Calculate average monthly spending
- Compare spending across different categories
- Visualize spending using bar charts and a pie chart

## Key Findings
- Total monthly spending: $9,800
- Average spending per student: $1,633.33
- Highest spending: Emma ($1,790)
- Lowest spending: John ($1,400)
- Largest expense category: Rent (59.7%)
- Second-largest category: Food (20.7%)

## How to Run
1. Download `student_spending_analysis.ipynb`.
2. Open the notebook in Google Colab.
3. Run all cells in order.

## Dataset
The project uses a small, manually created dataset containing six fictional students. The results are for educational purposes and are not representative of actual student spending.
